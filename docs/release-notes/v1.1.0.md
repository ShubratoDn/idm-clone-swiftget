## SwiftGet 1.1.0: download videos from web pages 🎬

### New

- **"Download this video" button.** Hover over a video on a web page and click the button that appears
  in its corner. SwiftGet downloads the **whole video from the first byte** with multiple connections,
  even if you've only watched a few seconds. When a page has several streams, the button lists them best first.
- Videos are named after the page title instead of a random file name.

### Fixed

- Videos played by normal web players (for example on Fiverr) were not detected. Browsers stream these
  videos in byte ranges, and the extension ignored those responses. They are now detected with their full size.
- The About dialog shows the real app version.

### Downloads

| File | Use it for |
| --- | --- |
| `SwiftGet_1.1.0_x64-setup.exe` | Recommended installer for Windows 10/11 (64-bit) |
| `SwiftGet_1.1.0_x64_en-US.msi` | MSI package for managed/silent deployment |
| `SwiftGet_browser-extension_v1.1.0.zip` | Chrome/Edge extension (load unpacked) |
| `SHA256SUMS.txt` | Checksums to verify the downloads |

### Upgrading

- **App:** run the new installer; your download list and settings are kept.
- **Extension:** unzip the new extension over the old folder, then click the reload icon on
  **SwiftGet Integration** in `chrome://extensions` (or `edge://extensions`) and reload open tabs.

> YouTube and DRM-protected sites are not supported.
>
> **Windows SmartScreen:** the installer is not code-signed yet. If Windows shows "Windows protected your PC",
> click **More info → Run anyway**. You can check the file against `SHA256SUMS.txt`.
