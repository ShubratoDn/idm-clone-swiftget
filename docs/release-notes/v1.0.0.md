## SwiftGet 1.0.0, first public release 🎉

SwiftGet is a free, open-source download manager for Windows. It speeds up downloads by fetching
each file over several connections at once, resumes broken downloads, and works with Chrome and Edge.

### Highlights

- **Multi-connection downloads** with dynamic segmentation (1–32 connections per file)
- **Pause & resume**, even after closing the app or restarting Windows
- **Copes with difficult servers**: carries on with fewer connections when a server caps them, and honours `Retry-After` on rate limits
- **Scheduler**: start/stop the queue at set times; exit, sleep or shut down when finished
- **Speed limiter** shared by all downloads
- **HLS video downloader** (`.m3u8`) with AES-128 support
- **Browser integration** for Chrome and Edge: download capture, context menu and video detection
- Classic, familiar interface with categories, a per-download progress window and a connection map

### Downloads

| File | Use it for |
| --- | --- |
| `SwiftGet_1.0.0_x64-setup.exe` | Recommended installer for Windows 10/11 (64-bit) |
| `SwiftGet_1.0.0_x64_en-US.msi` | MSI package for managed/silent deployment |
| `SwiftGet_browser-extension_v1.0.0.zip` | Chrome/Edge extension (load unpacked) |
| `SHA256SUMS.txt` | Checksums to verify the downloads |

> **Windows SmartScreen:** the installer is not code-signed yet, so Windows may show
> "Windows protected your PC". Click **More info → Run anyway**. You can check the file against `SHA256SUMS.txt`.

### Install the browser extension

1. Unzip `SwiftGet_browser-extension_v1.0.0.zip`.
2. Open `chrome://extensions` or `edge://extensions` and enable **Developer mode**.
3. Click **Load unpacked** and select the unzipped folder.

See the [README](https://github.com/ShubratoDn/idm-clone-swiftget#readme) for the full guide and the
[CHANGELOG](https://github.com/ShubratoDn/idm-clone-swiftget/blob/main/CHANGELOG.md) for details.
